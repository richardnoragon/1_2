2. **Tool Enhancements:**

     - Use consistent UI/UX patterns from the File Finder integration.

3. **UI/UX Consistency:**
   - Match styling, layout, and behavior of menu items with the File Finder menu.
   - Use icons and keyboard shortcuts where applicable.
   - Ensure accessibility and responsiveness.

4. **Code Structure:**
   - Modularize menu creation for maintainability.
   - Use event-driven architecture to handle menu actions.
   - Document each function and menu item clearly.

- Updated UI with integrated **File** menu.
