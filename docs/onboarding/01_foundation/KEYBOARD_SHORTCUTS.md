# Keyboard Shortcuts - Master RFU Navigation

> **Navigation**: [Main Hub](README.md) → **Keyboard Shortcuts**

> **Prerequisites**: RFU launched

Master these essential shortcuts to navigate RFU like a pro. Learn the most important ones in under 2 minutes.

## ⚡ **Essential Shortcuts (Learn These First)**

### Hub Navigation

| Shortcut | Action | Why It Matters |
|----------|--------|----------------|
| `Ctrl+1` | File Management tab | 80% of work happens here |
| `Ctrl+2` | File Operations tab | Advanced file handling |
| `Ctrl+3` | Analysis tab | Problem solving |
| `Ctrl+4` | Security tab | Data protection |
| `F1` | Help | Quick documentation access |

### Tool Management

| Shortcut | Action | Why It Matters |
|----------|--------|----------------|
| `Enter` | Launch selected tool | Faster than clicking |
| `Tab` | Navigate between tools | Keyboard navigation |
| `Ctrl+W` | Close current tool | Quick cleanup |
| `Alt+F4` | Close tool window | Standard Windows behavior |

## 📱 **Cross-Platform Notes**

### Windows

- Use `Ctrl` for all shortcuts
- `Alt+F4` closes windows
- `Windows+D` minimizes all (show desktop)

### macOS

- Replace `Ctrl` with `Cmd` (⌘)
- `Cmd+Q` quits application
- `Cmd+W` closes windows
- `Cmd+M` minimizes windows

### Linux

- Use `Ctrl` for all shortcuts
- `Alt+F4` closes windows
- May vary by desktop environment (GNOME, KDE, etc.)

## 🎯 **Efficiency Patterns**

### Common Workflows

```
Quick File Search:
Ctrl+1 → F → Ctrl+O → Select folder → F5

Batch Rename:
Ctrl+1 → R → Ctrl+O → Select folder → F2 → Edit pattern → Ctrl+P → Ctrl+A

Disk Analysis:
Ctrl+3 → S → Ctrl+O → Select drive → F5
```

### Pro Tips

- **Learn gradually**: Master hub navigation first, then tool-specific shortcuts
- **Practice daily**: Use shortcuts for one week to build muscle memory
- **Customize**: File → Preferences → Keyboard to modify shortcuts
- **Visual cues**: Menu items show shortcuts (File → Open shows Ctrl+O)

## 🚫 **What NOT to Memorize**

**Skip these advanced shortcuts initially:**

- Window management (`Ctrl+Tab`, `Ctrl+Shift+Tab`)
- Advanced tool functions (tool-specific F-keys)
- Menu navigation (`Alt+F`, `Alt+S`, etc.)
- Context menu shortcuts (`Shift+F10`)

**Focus on the essentials first!**

## ❓ **Troubleshooting Shortcuts**

### Shortcuts Don't Work

- **Check**: Caps Lock (affects Ctrl combinations)
- **Verify**: Tool has focus (click in tool window first)
- **Try**: Different keyboard layout (US vs International)
- **Reset**: File → Preferences → Keyboard → Reset to Defaults

### Conflicts with Other Software

- **Common**: Browser extensions, system utilities
- **Solution**: Customize RFU shortcuts to avoid conflicts
- **Check**: System-wide hotkeys (Windows: Win+R → msconfig)
