## 2. Modernization Patterns Applied

### 2.1 Assertion Conversions

| Original (unittest)        | Modernized (pytest)    | Count |
| -------------------------- | ---------------------- | ----- |
| `self.assertEqual(a, b)`   | `assert a == b`        | 45+   |
| `self.assertTrue(x)`       | `assert x`             | 25+   |
| `self.assertFalse(x)`      | `assert not x`         | 15+   |
| `self.assertIsNone(x)`     | `assert x is None`     | 10+   |
| `self.assertIsNotNone(x)`  | `assert x is not None` | 15+   |
| `self.assertIn(a, b)`      | `assert a in b`        | 12+   |
| `self.assertGreater(a, b)` | `assert a > b`         | 18+   |
| `self.assertRaises(E)`     | `pytest.raises(E)`     | 8+    |

### 2.2 Fixture Migrations

| Original (unittest) | Modernized (pytest)            |
| ------------------- | ------------------------------ |
| `setUp(self)`       | `@pytest.fixture` with yield   |
| `tearDown(self)`    | Cleanup in fixture after yield |
| `self.test_dir`     | Fixture parameter injection    |
| `TestCase class`    | Regular class with fixtures    |

### 2.3 Skip Patterns

| Original           | Modernized                                     |
| ------------------ | ---------------------------------------------- |
| `@unittest.skip`   | `@pytest.mark.skip`                            |
| `@unittest.skipIf` | `@pytest.mark.skipif`                          |
| Platform skips     | `@pytest.mark.skipif(os.name != 'posix', ...)` |

### 2.4 Module Availability Handling

All modernized tests include graceful module availability checks:

```python
try:
    from module import Class
    HAS_MODULE = True
except ImportError:
    HAS_MODULE = False

pytestmark = pytest.mark.skipif(
    not HAS_MODULE, reason="module not available"
)
```
